# The project

* [The project](overview.md) - The project beside the game: the roadmap, the itch.io page and how releases reach it, and the map of where the old flat docs and their sections went.
* [Roadmap](roadmap.md) - Roadmap toward a run that plays like the original: done (MegaMan kept in the run, Cross and Beast Out by story flags, warps, guardians, raised rooms, layouts) and next (stairs of other lengths).
* [Where the old docs went](moved.md) - Where each of the 27 old flat docs (EMULATION, ROM_DATA and the rest) and every section and ROM data row went, by old anchor, for the old names in commits, issues and notes.
* [Merging in parallel](merging.md) - How pull requests made side by side stay out of each other's way: what conflicted when `dev` was brought into a branch, measured; the files a tool writes, which `dev`'s workflow commits and no branch does (`tools/generated.py`); the registries kept a file an entry (`tools/shards.py`); the log folded from a file a change (`tools/log_fold.py`); what a branch does when it meets any of them; when a branch brings `dev` in, what that saves and what still conflicts.
* [Claims](claims.md) - What each branch in flight may take of the numbers branches share (chip ids, enemy ids, AI numbers, list numbers, song slots, free-space spans, units of work, `Run`): a file a branch in `docs/project/claims/`, written before the branch starts and held apart by `tools/claims.py`.
* [itch.io](itch.md) - The itch.io page's source, changed here first: its title, tagline, settings, tags, pictures (`tools/itch_art.py`) and theme, the files `tools/itch.py` pushes to butler channels, the browser build there, and each release's steps.

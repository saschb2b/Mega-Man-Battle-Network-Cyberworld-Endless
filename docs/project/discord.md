# Discord

The project's Discord server, made 19 November 2026, is the open place
to talk about the game: runs and folders, NetBattles, help and ideas.
GitHub stays where the work is tracked: a bug goes to the
[issues](https://github.com/saschb2b/Mega-Man-Battle-Network-Cyberworld-Endless/issues/new/choose)
whatever was said about it on Discord, and the server's rules and its help
forum say so (the owner: GitHub is the primary place, "especially for
bugtracking"; Discord is for the more open conversation that GitHub's
Discussions and Reddit only partly gave).

The invite is <https://discord.gg/mfZyWFvyfG>, made never to expire and
without a limit of uses. The README's top row, every page's footer on the
site (English and Japanese), the download page's line on questions and
runs, the FAQ's answer on new versions and the
[player's guide](../GUIDE.md)'s Follow updates and the [itch.io page](itch.md)'s Links (from 0.23.0) link it; the home pages
name it in their `sameAs` too. On GitHub, a question in the Discussions'
Q&A, "Is there a Discord server?" (#701), holds the invite as its
accepted answer.

## The server

Community mode is on, so it has a rules channel, a followable
announcements channel, forums, Onboarding and a Server Guide. Its
language is English; the owner's Discord client is German, so its
settings read in German there.

| Category | Channels |
| --- | --- |
| Start here (read-only) | `#rules`, `#announcements` (an announcement channel other servers can follow), `#links` |
| Community | `#general`, `#runs-and-folders`, `#screenshots-and-clips`, `#net-square` (opponents for NetBattles, trades, the week's DeepNet), `#battle-network` (the original games) |
| Help & ideas | `help`, a forum whose posts need a tag: Solved, Bug?, Setup & ROM, Saves, Online and one a system; `ideas`, a forum with a tag a topic and two only mods set, On GitHub (made an issue) and Not planned |
| Development | `#dev-talk` |
| Voice | Lounge |
| Mods (private) | `#mod-chat`, `#mod-log` (AutoMod's, the raid protection's and Discord's community messages) |

Roles: Developer (the owner), Moderator (messages, threads, timeouts,
kicks, bans, the audit log), Contributor, and two a member picks in
Onboarding, Release pings and NetBattle pings (the one anyone may
mention, to find an opponent). Onboarding asks what a player is there for
(runs, online, development, voice) and which pings they want; the Server
Guide's tasks are saying hi, showing a run, getting the game, finding a
NetBattle and reading the rules.

## Moderation

Members need an account older than five minutes, and may not mention
everyone or make emoji and events. Discord's raid protection, CAPTCHA and
DM spam filters are on, and media from every member is scanned. AutoMod
blocks spam, mass mentions, slurs and sexual content, and a rule of the
server's own, No ROM links, blocks the names of ROM sites with a message
that the game runs from the player's own dump, as the rules' second point
says ([What is original, generated or adapted](../game/fidelity.md) has
why the project carries no game data). Requiring two-factor
authentication for moderators waits on the owner's account having it.

## Posts there

What the owner's account posts on the server is in his own voice:
short, lowercase, "->" for what follows, no headings. The rules, `#links`
and the first announcement were written that way. A new version is
news for `#announcements`, beside its devlog post on [itch.io](itch.md)
and its trailer on [YouTube](youtube.md); a post there is still the
owner's to approve.

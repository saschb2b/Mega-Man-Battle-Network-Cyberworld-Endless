# The code

* [The code](overview.md) - What each part of the tree holds, file by file: a concept per folder (server, client, core, emulator, director, maps, screens, tools, platforms, site), the rows AGENTS.md's Layout table had.
* [The site, screenshots and clips](site-and-media.md) - What `web/` (the GitHub Pages site in BN6's PET look, its Japanese pages, the player and downloads), `docs/screenshots/` and `docs/clips/` (the trailer included) hold.
* [The server, its deployment and the wire](server.md) - What `server/` (the ROM-free Python server: presence, Trade Central, the week, the Arena, teams, stands, retention, backups), `deploy/` (Coolify) and `shared/online/` (the versioned wire contract) hold, file by file.
* [The anonymous statistics](analytics.md) - What `src/analytics/` holds: the anonymous statistics' answer, events and Umami payloads, the question, and each system's way to send them off the frame loop.
* [The builds: desktop and browser](builds.md) - How the desktop builds differ (CW_DESKTOP: a window, saves and the ROM in the user's data folder) and the browser build's limits (no threads, one frame per 1/60 s, IndexedDB through `platform_persist()`, BN5 read as data).
* [Online play's client](online.md) - What `src/online/` holds, file by file: the transport, a visit and the Square, emotes, Trade Central, the Arena's linked cores and rollback, Team NetBattles and two MegaMen a side, the NetPass and the stands.
* [The director: the run on the game](director.md) - What `src/director/` holds, file by file: the frame's course and its shared state, layers, checkpoints, encounters, bosses, home and Lan's HP, the requests, a dark layer's liberation, and the words files.
* [The engine's screens: the ROMs screen, SAVES, the start and title, the second screen](screens.md) - What `src/launcher/` (the ROMs screen and pickers), `src/saves/` (SAVES), `src/scenes/` (the start, title and error screen) and `src/second/` (the 3DS's and Android's second screen) hold, file by file.
* [The emulator, its hooks and the moved code](emu.md) - What `src/emu/` holds, file by file: the mGBA core, hooks and gamecalls, the moved virus families, Navis, chips and Souls, BN5's panels, free space and write claims, and the bn6*.h headers naming BN6's addresses.
* [The tests](tests.md) - What the ROM-free unit tests cover (`tests/test_core.c`, `test_backup.c`, `test_saves.c`, the transfer, discovery and map-slot tests, the Android saves and Steam scripts, the voice catalog) and the lint baselines.
* [The real world](world.md) - What `src/world/` holds: the real world and Central Town, BN6's indoor maps taken over as home's places (Lan's house, AsterLand, the Academy), the town's folk and their words.
* [The core: entry, platform, Options, ROM access, run state and saves](core.md) - What `src/core/` holds, file by file: main and startup, platform and input, Options, ROM access and RomLayout, chips and loot, BN5's records, the chip registry, run state, the .cwsave carrier, jobs, the economy's plans.
* [What stands on a layer](layer.md) - What `src/layer/` holds: the objects on a layer (NPCs, services, shops, choices, guardians), the chat parts in `scripts.c` and the words files the lines live in.
* [The platforms and their packaging](platforms.md) - What each platform's folder holds: the PortMaster port, the Linux, Windows, macOS, iOS and Android releases, the New 3DS, Switch, PS Vita, PS4 and PS5 builds, the Docker build images and the CI and release workflows.
* [Layer generation and layers as game maps](net-and-map.md) - What `src/net/` (layer generation: plan, signature rooms, detours, landmarks, set pieces) and `src/map/` (layers as BN6's maps: tiles learned, the map tables, Lan's HP) hold, file by file.
* [Graphics, sound and the Jukebox](gfx-and-audio.md) - What `src/gfx/` (sprites, ROM tiles, fonts, BN6's PET look, the QR code, BN5's tiles), `src/audio/` (the engine's MP2K, the device, the sound filter) and `src/jukebox/` hold, file by file.
* [Tools and skills](tools.md) - The research and test tools (romlab, uinput_keys.py, play.py, the cyberworld MCP server and cw.py, the voice catalog and dashboard) and the repository's skills (playtest-loop, game-design, trailer, agent-browser).
* [Developer tools inside the game](dev.md) - What `src/dev/` holds: `--dev` and its switches, the atlas, tour and pacing report, headless input and pictures (`capture.c`), and the tools run in the game's place (`--economy`, `--xdiff`, `--xrecords`).

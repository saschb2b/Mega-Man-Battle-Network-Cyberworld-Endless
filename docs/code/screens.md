# The engine's screens: the ROMs screen, SAVES, the start and title, the second screen

| Path | Contents |
| --- | --- |
| `src/launcher/` | The ROMs screen before the game on the desktops, Android and iOS (issue #97, [The player's guide](../GUIDE.md#the-roms-screen)'s The ROMs screen): `launcher.c` its course, `launcher_draw.c` its layout and picture, drawn on the game's own screen in the style of the second screen's PET panels (`second_frame.c`; a second display stays dark meanwhile), `launcher_art.c` the cartridges and open spots in three sizes (the project's own drawing, a label in its game's colours: BN6's green, BN5's blue, BN4's red; its face drawn from the player's ROM as it opens; the compact size where three stand side by side on a small screen), `launcher_roms.c` which cartridges are shown (BN6's, and one each extra ROM offered: rom.h's `xrom_offered`: BN5's and BN4 Red Sun's), what a chosen file is and the last start's record (`launcher.ini`, a line a cartridge shown), its words in `launcher_text.c` (a table of the cartridges' names and what each game lends, the notes composed from it); the system's pickers behind `pick.h` (`pick_desktop.c`, `pick_android.c`, `pick_ios.c`, `pick_none.c`; what they share for SAVES in `pick_saves.c`: `saves.ini`, the transfer place where it is a plain folder; their words in `pick_text.c`), the automatic copy to the transfer folder, a phone's ROM folder or any chosen one (`mirror.c`), and the two hooks the screen asks SAVES through, a dropped `.cwsave` and each frame's look at the copy's place (`launcher_saves.h`, filled by `saves.c`: the launcher includes nothing of SAVES, [the layers](layers.md)) |
| `src/saves/` | The SAVES screen (issue #114, [Portable saves](../engine/saves.md)), over the title or the ROMs screen: `saves.c` its course, `saves_actions.c` its buttons' work, `saves_draw.c` its picture, `saves_layout.c` where its buttons are, `saves_text.c` its words; the state its parts share in `saves_state.h` |
| `src/scenes/` | The start (`scene_intro.c`: the developer's boot screen, `intro_logo.c`, and MegaMan's word on GitHub, before the title at a plain start), the title (`scene_title.c`; its menu `title_menu.c`, the JACK-IN SETUP after NEW GAME `title_setup.c` in three tabbed pages, RUN, HELP and EXTRAS ([the extras](../game/meta/extras.md)), its words `title_setup_text.c`; the run summary `title_summary.c`, its PET text `title_summary_text.c` and MegaMan's words `title_lines.c`), the screen a start without its ROM shows where there is no ROMs screen (`scene_error.c`: PortMaster, the 3DS) and the sprite gallery |
| `src/library/` | The Library ([The Library, a page per entry](../game/meta/library.md)): the PET's Library row's screen over the held game, a tab each for BN6, BN5 and BN4. `library.c` its state and keys (BN6's Library's: Left and Right the pages, L and R the list a screenful, B or START leaves; taps), `library_draw.c` its picture, BN6's own Library measured pixel for pixel (the card, the panel and field, the rows' letters in the ROM's font, stars, cursor, scroll bar) with the entries as tags on the band, and where a tap takes each part, `library_text.c` its labels |
| `src/second/` | The second screen (issue #72): the 3DS's bottom screen, Android's second display. It follows BN6's screen as the DS games' PET followed theirs: `second.c` reads which screen the player is on once a frame (BN6's modes, [ROM data](../rom/overview.md)) into a state the draw reads (on the 3DS the draw runs while the core's thread runs the next frame), `second_read.c` reads each panel's facts, `second_frame.c` draws the PET's frame (in `tools/site_art.py`'s colours, measured from BN6's PET), each screen's panel has a file of its own (the Square's emote palette, a tap an emote or phrase, `second_palette.c`), and `second_text.c` holds the panels' words Since the Library is the run's own screen (`src/library/`), its panel reads that screen's cursor (`second_library_up`, `library_cursor`) and its rows count each entry's page. |

<h2 align="center">A run with a finish line. A next run with more to choose.</h2>

<p align="center"><b>The second alpha of Cyberworld Endless:</b> the short net, a setup that grows with you, BN6's title marks, and builds for Windows and macOS.</p>

---

## 🏁 A run you can finish

A run is now **the short net**: three acts, then the **Cybeast Nest** on layer 10. Delete its guardian and the run is won, about an hour from the jack-in. Win once and the **endless net** opens, the old run that goes on, harder, as deep as MegaMan can get.

## 🧬 Every run leaves you something

Options, never power: MegaMan starts every run as strong as the first time. From your second run, NEW GAME opens a **jack-in setup**:

- **Net:** the short net, or the endless net once you have won.
- **Folder:** BN6's own, or one you opened: **Blade** (swords in S for LifeSword) once any guardian falls, **Storm** (Elec chips, double on Aqua) once an Aqua guardian does. The setup lists what is still closed and how it opens.
- **Threat:** five rungs, each one new rule (viruses a version stronger, heals only mid-act, dearer dealers, EX guardians, SP navis in Servers), each opened by a win on the one below.
- **Help:** two more HPMemory, a heal on every layer, gentler battles. Switch them on as you like; helped runs count for everything.

The run's summary names what it opened and the closest goal. And milestones put **BN6's own title marks** on the title screen: Gregar's head for a won short net, Bass for the endless net's Nest, the S for the Secret Area, the green disc for a win on the top threat rung. A mark you just earned blinks in after the summary.

## 💻 Windows, macOS and Steam

- **Windows 10 and 11:** an installer (for you alone, no administrator; Start menu, uninstall in Settings) or a zip to unpack anywhere. One .exe.
- **macOS 11 and newer:** one app for Apple silicon and Intel Macs, in a .dmg.
- **Steam:** the game adds itself to Steam with its own library art: a capsule, a banner, a logo and the icon. On a Steam Deck it is one command in Konsole for the Flatpak; the AppImage offers it on its first start.

## 🛠️ Smoother runs

- **Returning players hear less:** one-page arrival words and gift greeting, and a Net Dealer met again in the same act greets in a line.
- **Programs you forgot:** a NaviCust program you have but never placed on the board is named in L's briefing until it is.
- **No more wrong talks:** navis you talk to keep apart, so an A for the heal Prog never opens the dealer beside him.
- **Fairer starts:** the first battle is no lone ice Piranha, act 1's guardian is BlastMan, DiveMan or SpoutMan alike, and a Server says how strong it is before it asks.
- **The Custom screen:** an L or R pressed up to a second and a half early is kept, and a d-pad press drops it.

## 📥 Get it

| Where you play | Download | Then |
| --- | --- | --- |
| **In the browser** | nothing: [play here](https://saschb2b.github.io/Mega-Man-Battle-Network-Cyberworld-Endless/play/) | Choose your ROM; runs and saves stay in your browser |
| **Windows** | `cyberworld-endless-setup-x64.exe` or `cyberworld-endless-windows-x64.zip` | Run the installer, or unpack the zip and start `cyberworld-endless.exe`. If Windows says it protected your PC: **More info**, **Run anyway** |
| **macOS** | `cyberworld-endless-macos.dmg` | Drag the app into Applications. On the first start, **System Settings > Privacy & Security > Open Anyway** (it is not notarized) |
| **Steam Deck** | `cyberworld-endless.flatpak` | Open it in Desktop Mode (Discover installs it), then add it to Steam with its art: one line in Konsole, [in the README](https://github.com/saschb2b/Mega-Man-Battle-Network-Cyberworld-Endless#on-a-steam-deck) |
| **Linux PC** | `cyberworld-endless-x86_64.AppImage`, `cyberworld-endless_amd64.deb`, `cyberworld-endless.flatpak` or `cyberworld-endless-linux-x86_64.tar.gz` | Make the AppImage executable and start it, or install the `.deb` or the Flatpak from your software centre |
| **ROCKNIX handhelds** (PortMaster) | `cyberworld.zip` | Unzip into `ports/`, put your ROM in `ports/cyberworld/rom/`, refresh the game list |

**You need your own ROM:** *Mega Man Battle Network 6: Cybeast Gregar (USA)*, unmodified. On first start the game finds it by its contents (in Downloads, EmuDeck's or RetroDECK's folders, or wherever you point it). Nothing in these downloads contains game data. Step-by-step guides are in the [README](https://github.com/saschb2b/Mega-Man-Battle-Network-Cyberworld-Endless#install).

## 🧪 An alpha, honestly

- **A run saved by 0.1.0 starts afresh:** the run's save changed with the setup. Your best depth and your guardians' memory of you stay.
- **Windows and macOS are new:** built and started by our checks (the Windows build under Wine, the Mac app on a Mac in CI), but not yet played through on real machines. Tell us how they run.
- Balance is still moving session by session, the threat rungs most of all.
- Only Cybeast Gregar (USA) works for now; Falzar, other regions and the Legacy Collection don't yet.

Found a bug, a dead end or a fight that felt unfair? [Open an issue](https://github.com/saschb2b/Mega-Man-Battle-Network-Cyberworld-Endless/issues). Everything that changed since 0.1.0 is in the [changelog](https://github.com/saschb2b/Mega-Man-Battle-Network-Cyberworld-Endless/blob/v0.2.0/CHANGELOG.md).

# Cyberworld Endless: the knowledge base

What the project knows, for the agents and people who change it: an Open Knowledge Format (OKF v0.2) bundle. Each folder's `index.md` lists its concepts with one line each; open only the ones the task needs. Every concept opens with frontmatter: its `type`, a one-sentence `description`, `tags`, who wrote it and when (`generated`) and what it rests on (`sources`, where given). How the bundle is kept is AGENTS.md's Knowledge base section; `build.py lint` validates it.

# Sections

* [The run: how it plays](game/) - Progression, the meta layer, the economy, Liberation Missions, guardians, the NaviCust, the rival, the PET and what is original
* [Where it is played](world/) - The net's generated layers, home and the real world
* [Running BN6](engine/) - The emulator and the memory it writes, hooks, sound, saves and the screens drawn in BN6's look
* [Other games' ROMs](multirom/) - BN5's battles, Navis, chips and Souls in BN6's engine
* [Online](online/) - The Net Square, the NetPass, Trade Central, the week's net, the Arena and the link cable
* [The ROM map](rom/) - Where ROM data lives and how each address was found, and the symbol files
* [Research](research/) - What the original games have, do and lack, and the sources it was verified in
* [Reverse engineering](re/) - Where the reverse-engineering work stands (the ledger, written out)
* [Voice](voice/) - How every character talks, the catalog of every line and its review
* [Developer tools](devtools/) - The tools that build, play, capture, measure and compare
* [The code](code/) - What each part of the tree holds, file by file
* [The project](project/) - The roadmap, the itch.io page and where the old flat docs went
* [Release notes](releases/) - The players' notes of each release

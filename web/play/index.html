About the browser player

The run is saved in this browser on every new layer; CONTINUE on the title picks it up. Save backup and Load backup in the menu open the game's SAVES screen. Export downloads one cyberworld-endless.cwsave file; Import shows this browser's saves and the file side by side before replacing them. You can also drop a .cwsave on the player. The same file works on the other systems, and Undo last import brings back what was replaced. Controls, screen settings, volumes and your statistics answer stay here. Clearing this site's data deletes your ROMs and saves.

On a phone or tablet the game fills the screen and draws its own buttons round the picture; added to the home screen, it opens full screen. Also for Windows, macOS, Linux, the Steam Deck, Android, handhelds and the 3DS: the downloads.

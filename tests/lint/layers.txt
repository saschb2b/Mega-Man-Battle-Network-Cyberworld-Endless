# The code's layers (build.py lint, tools/layers.py; docs/code/layers.md).
#
# A unit is a folder of src/, or the part of one a line "unit = folder/pattern ..."
# names (the first line that matches a file takes it; what no line takes is its
# folder's own unit). A line "unit: units" says what a unit's files may include
# of src/ beside their own unit; "*" is every unit on the lines above. The lines
# stand lowest first, and a unit names only units above its own line, so the
# rules themselves hold no cycle.
#
# An include the rules do not allow fails lint, but those listed in
# layer_violations.txt, which only shrinks. A new folder or a new unit needs
# its line here, at its place in the order.
